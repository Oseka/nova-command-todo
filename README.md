# Task 3: Dynamic To-Do Application (Nova Command)
A sci-fi mission-control to-do app. Every task is a mission to a fictional world, assigned to an original crew member.
Plain HTML, CSS and JavaScript. Open index.html in a browser.

## Features
- Add missions with a destination, crew member, threat level and optional launch window
- Status tracking: On pad > In orbit > Landed (progress bar and stats HUD with success rate)
- Live T-minus countdowns and an "Overdue" warning
- Filter by status, search by text, scrub (delete) and archive landed missions
- Interactive starfield: mouse parallax, hyperspace streaks on launch, particle burst on landing
- Keyboard shortcuts: N (new mission), / (search)
- Tasks are saved in Local Storage and survive a refresh
- Responsive layout, keyboard-accessible controls, reduced-motion support
